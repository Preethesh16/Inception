# Synthetic dataset contract

Generator: `backend/inception/seed.py`; seed 2026; start 2026-02-10 UTC.

18 series: six fictional hospitals, three supplies. 240 days of observations plus 28 hidden days. The scenario starts after 237 completed days and reveals the last three on “Advance to incident.”

| Field | Meaning |
|---|---|
| facility_id | Fictional facility A–F |
| supply_id | ORS sachet / SAL 500 ml bag / MSK mask |
| date | Completed observation day, UTC |
| quantity | Observed consumption, nonnegative integer base units |
| complete | Whether this is a complete observation |
| stockout_censored | Whether consumption was constrained by available stock |
| patient_load | Legacy synthetic metadata; optional and excluded from forecasting |
| emergency_share | Legacy synthetic metadata; optional and excluded from forecasting |
| report_indicator | Historical report indicator; no future reports are injected |

Demand uses a Poisson process with weekly factors, modest trend and predetermined incident windows. A/B ORS surges begin at indices 100, 180 and 237. F has one isolated mask-consumption spike at 220. C has missing observations; F saline includes stock-out-censored points.

These mechanisms are engineering fixtures. They have not been fitted to real hospital data or externally validated.

The historical ledger begins from an artificial opening balance and replenishes when necessary. At the live demo boundary, each facility starts from a deliberately constructed batch snapshot used to exercise shortage, expiry and allocation cases. That boundary is a new opening balance, not claimed to be a continuous real-world ledger.

## Inventory import

CSV columns:

`id,facility_id,supply_id,lot,quantity,expires_at,storage,unit`

IDs must be unique, quantities nonnegative integers, expiry a future timezone-aware timestamp, unit and storage an exact match, and facility within the current role. All rows validate before any are committed.

Example:

```csv
id,facility_id,supply_id,lot,quantity,expires_at,storage,unit
A-ORS-NEW,A,ORS,LOT-NEW,100,2027-01-01T00:00:00Z,ambient,sachet
```

Imports add new inventory batches and receipts. They do not overwrite historical consumption. Source observations are generated by the reproducible generator; a separate real-data consumption adapter is outside this prototype.
